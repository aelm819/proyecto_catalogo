# 🛒 ElectroCatálogo - E-Commerce & Admin Panel

¡Bienvenido a ElectroCatálogo! Este es un proyecto completo de tienda online con un panel de administración (CRUD) creado desde cero.

## 🚀 Tecnologías Utilizadas
* **Backend:** PHP 8+ y PDO (Seguridad contra inyecciones SQL).
* **Base de Datos:** MySQL / MariaDB.
* **Frontend:** HTML5, CSS3 y Bootstrap 5 para un diseño responsivo.

## ✨ Características Principales
- **Catálogo Público:** Cuadrícula de productos dinámica con paginación automática.
- **Panel de Control Seguro:** Sistema de login con variables de sesión (`$_SESSION`).
- **Gestión de Productos (CRUD):** Creación, edición y borrado de productos con subida de imágenes al servidor.
- **Gestión de Fabricantes:** Relación de bases de datos para asignar marcas dinámicamente a través de menús desplegables.

## ⚙️ Instalación Local
1. Clona este repositorio.
2. Importa el archivo `electro_catalogo.sql` en tu servidor local (XAMPP/MAMP).
3. Configura las credenciales en `conexion.php`.
4. ¡Disfruta del proyecto!
